# Archive

Folder untuk **file asli** yang tidak lagi dipakai di root atau struktur aktif.

## Kebijakan

Saat merapikan folder:
- **Jangan hapus** file original
- **Pindahkan/salin** ke `archive/originals/` dengan nama asli
- File aktif untuk generator tetap di `input/`, `template/`, `output/`

## Isi

```
archive/
├── originals/     # File asli (nama lama, sebelum reorganisasi)
│   ├── 202605_Program dan Data Weekly Report.*
│   ├── 202605_Detail Laporan_Lutfi_GitHub.*
│   ├── 202606_Program dan Data Weekly Report.*
│   ├── Contoh Format.docx
│   ├── Laporan Bulanan_Lutfi Ihsan - Bulan 2026.docx
│   └── Laporan Bulanan_Lutfi Ihsan - Mei 2026.docx
└── data/          # Data pendukung lama
    └── _prs_may.json
```

> Catatan: File di `originals/` dipulihkan dari salinan terbaik yang tersedia
> (`input/`, `template/`, `output/`). Screenshot media asli ada di `template/media/`.
